## 🚀 Featured project

### 🔎 [logarc](https://github.com/FRTX045/logarc)

**Reconstruct what one IP address actually did on a web server, from its access logs.**

An access log is thousands of flat lines. logarc groups one visitor's requests into a few **activity episodes** and links them into a timeline of the attack:

```
browsing → reconnaissance → directory enumeration → SQL injection → data access
```

Every finding links back to the exact raw log lines it's based on, so the evidence is always there to check.
